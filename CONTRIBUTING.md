# Contributing

Thanks for looking. This is a solo project, so here's how it works.

**Bug reports are the most useful thing you can send.** Open an issue with what you did, what you expected and what happened. *About & updates → Report a bug* gives you a block of technical details to paste in.

**A wrong battle result?** The engine is a port of Pokémon Showdown's simulator, and Showdown is the reference. Say which move, ability or item is involved, and include a replay if you can.

**Ideas and pull requests.** Please open an issue first. This repository is an export of my development tree, so I apply accepted changes by hand there and they come back here with the next release. That's also why the code here has no comments.

**Building on it.** Fork it and go: the code and the weights are MIT-licensed. *Building from source* in the README has the steps.

**Please don't** use it, or anything built from it, to play on Showdown's ladder or servers. See Fair play in the README.
